# 서울 데이터 연결 작업 내역

## 반영 내용
- 카카오 장소 검색과 자동차 길찾기 API를 추가했습니다.
- 팀 명세의 교통·혼잡도·주차 조회 경로를 기존 API와 호환되게 추가했습니다.
- SGIS 행정동, 서울 공식 121장소 관측 경계, S-DoT 통행량, ITS CCTV, 교통안전공단 주차정보를 연결했습니다.
- S-DoT 10분·주차 24시간·행정동 7일 자동 수집을 구성했습니다. ITS 목록은 자동 호출하지 않습니다.
- 대체·지연·누락 관측과 미확인 빈자리를 구분하며 실제 API 키는 이 main 변경에서 제외했습니다.

## 확인 결과
- 백엔드 단위·API 테스트 63개 통과.
- 공식 장소 경계 121개 적재 및 신규 API 정상 응답 확인.
- CCTV 표본의 HLS 목록과 하위 자료 접근 확인. 모든 카메라의 재생·지연은 미검증.

## 남은 범위
- 주차 시설·운영정보는 부분 수집입니다.
- 관리자 인증·수집 상태 API와 AI 챗봇은 별도 구현이 필요합니다.
- 실제 키는 각 개발자의 .env에 입력합니다. .env.example과 docs/API_CONTRACT.md를 참고하세요.
