# AI·추천 품질 평가

중심 담당: 백엔드 검증·AI 추천.

`tests/`의 코드 동작 검사와 함께 관리할 품질 평가 자료·도구의 위치다. 현재 평가기와 실제 사례는 없으며 모델을 호출하지 않는다.

- [cases](cases/README.md): 조건 해석·후보 비교·설명 사실성의 고정 입력과 기대 결과.
- [results](results/README.md): 실행별 평가 결과. 생성 결과는 기본적으로 Git에서 제외한다.
- 향후 평가 스크립트는 이 폴더에 추가하고 `app/modules/ai/`, `app/modules/recommendation/`의 실제 구현을 가져와 사용한다. 알고리즘·프롬프트를 평가 폴더에 복사하지 않는다.

첫 평가는 보관/모의 응답으로 구성한다. 실제 Bedrock 평가를 도입할 때는 별도 실행 명령·필요 설정·예상 호출 수·결과 저장 위치를 명시한다. 기본 pytest나 배포 과정에서 유료 평가가 자동 실행되도록 연결하지 않는다.

결과에는 코드·프롬프트·모델 설정·사례 버전, 입력 조건, 품질 판단 근거와 실행 환경을 기록한다. 품질 점수의 합격 기준은 평가 사례를 합의할 때 정한다.
