# 데이터 수집·처리

주기적 API 응답에서 필요한 필드를 메모리에서 추출·검증해 정형 DB에 직접 저장한다. 응답 원문·선택본·처리 보고서·체크포인트를 파일이나 JSONB로 보관하지 않는다. 실패한 대상은 이전 정상값과 실제 시각을 유지하며 최근 시도 상태와 짧은 회차 요약을 기록한다.

```text
기준정보 반영: 현재 data 파일 → 파싱·검증 → 정형 기준정보 DB
정기 수집: 외부 API 응답 + DB 기준정보 → 정규화 → 트랜잭션 적재
조회: 정형 DB → 지도 공개본·제품 API
```

현재 기준파일은 명시적인 반영 명령에서만 읽는다. 운영자가 파일을 교체하면 검증에 성공한 자료를 DB에 반영한다. 정기 수집·API·지도 공개·중단 복구는 파일에 접근하지 않는다. 필요한 기준정보가 DB에 없으면 선행자료 부족으로 종료하며 파일을 자동으로 읽어 채우지 않는다.

| 위치 | 역할 |
| --- | --- |
| `collectors/` | 제공처 요청·페이지 순회·응답 구조 확인과 필요한 입력 선택 |
| `normalizers/` | 필드·좌표계·단위·시각 검증과 정형값 변환 |
| `pipelines/` | 수집 잠금·회차 처리·부분 실패·트랜잭션 적재 연결 |
| `identity.py` | 처리 버전·값 지문 생성 |
| `results.py` | 처리 단위·채택/거절/중복/충돌 수와 사유 |
| `app/repositories/` | 정형 DB 저장·조회와 공간 연산 |
| `app/models/`·`migrations/` | 현재 테이블과 스키마 이력 |
| `jobs/` | 단발 명령·별도 worker 스케줄러 |

정기 수집은 FastAPI 요청이나 lifespan에서 실행하지 않는다. 실행 명령·수집 간격·기준정보 초기화 순서는 [jobs 안내](../../../jobs/README.md)를 따른다. 최신 스키마는 `0012`이며 앱 모델은 34개 테이블이다.

## 저장과 실패 처리

- 서울 등록·시영·CITYDATA 주차는 원천별 필드명을 공통 시설·요금·조건·운영시간·현황으로 변환한다. 등록·현황의 시각을 분리하며 정상 0과 미제공을 구분한다. 부분 입력이나 식별 충돌로 기존 시설을 일괄 비활성화하지 않는다.
- CITYDATA는 현재 응답의 인구·주차 필드를 사용한다. 여러 장소의 주차 후보를 메모리에서 병합하고 실제 인구/주차 저장 수량을 회차에 집계한다. 저장 응답을 재생하는 별도 주차 투영 명령은 없다. 도로 좌표는 명시적 도로 기준정보 반영 때 교차 검증에 사용한다.
- 전국 주차는 시설·운영정보의 다음 페이지와 현재 스캔 지문을 정형 DB에 저장한다. 데이터와 진행 위치를 함께 커밋하며 실패한 페이지는 다음 회차에 이어받는다. 완료·교체된 스캔 지문은 삭제한다. 요금 시간은 분 단위이며 시각이 없는 빈자리는 수신 후 1시간 정책을 적용한다.
- TOPIS는 속도·통행시간의 정상 0·부분 결측·관측 없음을 구분한다. 전체 활성 도로를 수집하며 일시 오류는 도로별로 재시도한다. 최대 50건 또는 1초마다 관측·최근 시도·회차 집계를 함께 커밋한다. 중단 시 커밋된 성공분은 유지하고 응답을 파일로 재생하지 않는다.
- S-DoT는 설치정보와 관측 수집을 분리한다. 미관측·충돌·과거 시각은 마지막 정상 관측을 덮지 않는다. 설치 수와 관측 갱신 수는 별도로 판단한다.
- SGIS는 검증된 경계와 도로↔행정동 관계를 함께 반영한다. 불완전한 목록으로 누락 행을 비활성화하지 않는다. 공식 도로선·매핑은 순번·공간 대응 검증을 통과한 기준정보만 반영한다.

출처별 종료된 최근 20회 요약만 유지한다. 진행 중인 회차와 현재 관측·최근 시도·전국 페이지 진행은 요약 정리의 영향을 받지 않는다. 같은 위치·형상은 공간 UPDATE를 생략한다. API 조회는 읽기 전용 스냅샷에서 커밋 전 값을 일관되게 읽는다.

정형 저장 후 지도 공개는 별도 트랜잭션으로 수행한다. 공개 실패가 이미 저장한 관측을 되돌리지는 않으며 DB에서 재공개할 수 있다. 조회는 관측의 실제 수신/관측 시각과 최근 시도 상태를 함께 판단한다. 수집의 `accepted` 수량이 곧 현재 활용 가능한 관측 수량은 아니다.

세부 경계는 [수집기](collectors/README.md), [정규화](normalizers/README.md), [파이프라인](pipelines/README.md) 안내를 참고한다.
