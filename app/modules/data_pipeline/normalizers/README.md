# 정규화 작성 위치

원본 코드를 공통 코드로, 좌표·단위·시각을 합의된 형식으로 변환하고 잘못된 기록을 구분한다. 주차·교통과 정형 저장용 필드 변환을 담당한다. 시영주차 좌표 연결은 등록 좌표가 하나로 결정되는 경우에만 적용하며 입력 원본을 수정하지 않는다.

DB·HTTP 없이 고정 자료로 시험할 수 있는 함수로 작성한다. 원천 시각과 수집 시각을 구분하고 미확인을 실제 0으로 바꾸지 않는다. 출처별 특수값·잘못된 좌표·누락 사례는 `tests/fixtures/`와 `tests/unit/data_pipeline/`에 함께 추가한다.

`values.py`는 숫자·정수·시각·Y/N을 `value`, `state(valid/missing/invalid)`, `reason`으로 반환한다. 0은 유효하며 음수·비정수·비유한 수·불리언의 수치 변환을 허용하지 않는다. 숫자형은 비음수 관측량용이다. 시각에 시간대가 없으면 KST로 해석하고 명시된 시간대는 유지한다. 미래 시각 검사는 호출자가 수신 시각을 `not_after`로 전달한다. 원천 시각이 없다고 수신 시각을 대신 넣지 않는다.

`citydata.py`는 요청·응답의 장소 식별과 내부 인구 행을 검증한다. 인구 섹션 누락·빈 목록·잘못된 구조를 구분하고, 같은 장소의 여러 행은 현재 저장하는 관측 필드가 모두 같을 때만 하나로 사용한다. 다른 값이 있으면 임의로 첫 행을 선택하지 않는다.

`parking.py`는 서울 주차의 식별·위치·출처를 확인하고, `parking_attributes.py`는 출처별 원천 필드를 요금(`fees`)·이용 조건(`conditions`)·운영시간(`operating_hours`)·현황(`availability`)·항목별 사유(`field_issues`)로 변환한다. 이 값들은 메모리의 처리 결과이며 DB의 JSON 컬럼이 아니다. 원천 키를 담던 `details`와 시영 값을 도시데이터 키로 바꿔 쓰던 분기는 제거했다.

`parking_resolution.py`는 중복·충돌 선택과 기존 출처 UUID의 대응을 순수 함수로 판정한다. `identity_key`는 과거 해시를 찾는 단서이며 공개 시설 ID가 아니다. 같은 출처·코드 안에서 과거 대응 해시, 정확한 위치, 비어 있지 않은 이름·주소 쌍의 유일한 대응을 확인한다. 단서끼리 다른 UUID를 가리키거나 여러 입력이 하나의 UUID를 요구하면 보류한다. 코드 단독·이름 유사도·근접 거리로 시설을 합치지 않는다. 기존 대응 없는 같은 코드의 다른 위치는 각각의 공간으로 저장한다.

한 회차에서 같은 위치·코드의 선택된 정형 값이 모두 같은 입력만 중복으로 묶는다. 요금·조건·이름 같은 등록값이 다르면 현황 시각이 달라도 충돌로 보류한다. 등록값이 같고 현황만 다를 때는 유효한 관측 시각이 모두 다를 경우에만 최신 관측을 선택하며 오래된 행을 중복으로 세지 않는다. 동일 시각 충돌이나 시각 미확인도 보류한다. 수신 시각·입력 위치는 사실 비교에서 제외하고 같은 회차의 후보 선택에만 사용한다.

CITYDATA의 등록 행(`CUR_PRK_YN=N`)과 현황 행(`Y`)이 함께 있는 경우는 `parking_merge.py`의 보완 병합 규칙을 먼저 적용한다. 같은 출처·코드·정확한 좌표에서만 등록 이름과 비어 있지 않은 필드를 보완한다. 양쪽의 수용량·요금·주소 등이 실제로 다르면 보류하며 0을 결측으로 보지 않는다. 요금 시간·금액은 한 행의 쌍으로 선택하고 현황은 원래 관측 시각·수신 시각을 유지한다. 메모리의 입력 위치와 `merge_summary`로 병합을 설명하며 원문/가공본 ID를 저장하지 않는다.

요금은 원/분이며 기본·추가 요금 쌍의 사용 가능 여부를 별도로 표시한다. 일 최대요금 0이나 기본요금 0만으로 무료를 판정하지 않는다. HHMM의 유효 범위를 검사하고, 종료 `2400`은 익일 자정으로 표현한다. 같은 시작/종료와 역순 시각은 근거 없이 24시간·익일 운영으로 확정하지 않는다. 평일·주말·공휴일은 각각 유지한다.

시영 현황은 총면수·주차 차량 수·제공 상태·관측 시각이 유효할 때만 빈자리를 계산한다. 도시데이터의 제공 빈자리는 다시 차감하지 않는다. 현황 시각은 `availability.observed_at`, 등록 갱신은 `source_updated_at`, 수신은 `collected_at`으로 분리한다. 미확인 제공 코드는 코드·설명을 보존하고 사용 가능으로 확정하지 않는다. `usable`은 입력 검증 결과이며 최신성 허용 시간이나 시설 간 집계 범위 검증까지 완료했다는 뜻은 아니다.

`storage_fields.py`는 주차·인구 값뿐 아니라 도로선·교통 관측·관측영역·행정동·서울 경계의 저장 필드를 구성한다. GeoJSON은 순수 값으로 전달하고 PostGIS 표현식 생성과 DB 참조 확인은 저장소에서 수행한다. 출처·대상 식별, 처리 버전과 지문 생성은 상위 모듈의 `identity.py`에서 관리한다.

주차 요금·이용 조건은 출처별 등록 컬럼, 반복 운영시간은 요일/구간별 행, 상세 사유는 항목별 행, 현황은 마지막 채택 관측과 최근 시도의 정형 컬럼에 연결한다. 평일·주말·공휴일을 별도로 보존하고 기존 API 표현이 지원하지 않는 요일은 notes로 표시한다. 저장 판단은 `repositories/parking_state.py`에서 수행한다. B12에서 정식 0010 마이그레이션으로 확정한 구조다.

`supplemental.py`는 SGIS 경계 값을 구성한다. 좌표계 변환과 경계 포함 여부는 공간 저장소가 처리한다. CCTV 원문 보관 경로와 관련 함수는 제거했다.

`sdot.py`는 센서 설치 파일의 헤더·식별자·장비 시리얼·좌표·동일 코드 충돌과 관측값을 검증한다. 숫자 ID는 정수/숫자열만 허용하고 소수·불리언을 잘라 쓰지 않는다. 관측 수량은 0 이상 signed bigint 범위의 정수만 허용한다. 센서별 최신 측정 시각을 선택하고 같은 측정 시각이면 가장 늦은 유효 DATE를 선택한다. 두 시각이 모두 같은데 수치가 다르면 충돌로 보류한다. DATA_NO는 보존하되 번호별 우선순위를 부여하지 않는다. 10분 구간의 시작/끝을 추정해 측정 시각을 이동하지 않는다. DATE와 원래 SERIAL·MODELNAME·페이지 수신 시각을 선택본에 유지한다. 최신 선정은 실제 시각으로 비교하고 요약 시각은 UTC로 통일하며 원래 offset은 입력 근거에 보존한다. 미래 측정/제공처 시각은 페이지 수신 시각에 대조한다. 수신 시각 미확인이면 미래 검증을 완료했다고 표시하지 않는다. 설치만 있음·관측 0·무효·충돌·일부 메타데이터 미확인을 구분한다. B10의 `pipelines/sdot.py`와 `repositories/sensors.py`가 DB 설치정보·현재 응답과 정형 저장을 연결한다.

`official_files.py`는 TOPIS ID·유한 좌표·정점 순서 검증, 순번이 빠진 도로 제외, 공식 매핑 순번·다대다 관계 보존과 도로·장소 Feature 구성을 담당한다. 도로 변환 결과의 좌표 범위를 검증하며, 장소 경계의 내부 링도 공간 처리에 전달한다. 파일 읽기와 PostGIS 호출은 포함하지 않는다.

`road_reference.py`는 두 공식 파일의 헤더·독립 버전/해시·기준일과 완전 입력/검토한 제외 조건을 확인한다. 링크 채택 수, 원본 행/빈 행/중복 행, 미연결 매핑, 매핑 없는 도로, 미확인 순번과 중복 순번을 단위별로 분리한다. 순번이 없으면 관계를 유지하면서 `sequence_status=unknown`과 저장 키 0을 쓰고, 제공된 순번이 여러 관계를 가리키면 `ambiguous`로 기록한다. ID 숫자 정렬로 진행 순서를 추정하지 않는다.

TOPIS 수집 대상 선정과 회차 결과 판정은 `pipelines/topis_rules.py`에서 담당한다.

`road_traffic_fields()`는 속도·여행시간의 유효/결측/무효를 각각 검사하고 `value_status`, `field_issues`, `value_counts`를 함께 반환한다. 정상 0은 유지하며 NaN·무한대·음수·불리언은 거절한다. 두 값이 유효하면 `valid`, 하나만 유효하면 `partial`, 모두 없으면 `missing`, 유효값 없이 오류가 있으면 `invalid`다. 이 품질 정보는 처리 보고서용이며 교통 테이블의 신규 컬럼이 아니다. 원천 관측 시각은 미제공이므로 `observed_at=NULL`을 유지한다.

`national_parking.py`는 실제 확인한 관리 ID/시설/운영/현황 키만 변환한다. 시설은 서울 주소 구분·유효 입구 좌표가 필요하며 시설 없거나 대응이 모호한 부속 자료는 보류한다. HHMMSS의 초와 요일/구간을 보존한다. 기본·추가 요금 시간은 사용자 확인에 따라 분으로 저장하며, 양수 시간과 유효 금액이 함께 있어야 비용 계산에 사용할 수 있다. 0원은 유지하고 1일 정액은 최대요금과 분리하며 월 정기권은 제외한다. 전국 현황은 관측 시각이 없어 시도 수량/수신 시각을 보존한다. 내부 조회는 이 수신값을 1시간까지 허용하며 원천 관측 시각은 생성하지 않는다.

`road_geometry.py`는 CITYDATA 도로 좌표의 유한값·범위·서로 다른 정점을 검사하고 같은 표준 ID의 좌표 변형과 근거를 모은다. 완전히 같은 좌표만 중복으로 묶으며 충돌·무효 기록을 마지막 행으로 덮지 않는다. PostGIS가 계산한 대응 구간 지표를 판정하고 자료 없음/부족·공간 불일치를 구분한다. 30m 허용 폭·90% 포함·길이비 0.8~1.25·독립 ID/형상 각 10개는 내부 보수적 기준이며 제공처의 보증 수치가 아니다. 좌표 배열 순서는 실제 통행 방향으로 확정하지 않는다.

인구 `population()`은 범위·등급·대체 여부·시각의 개별 상태와 사유를 반환한다. 유효한 한쪽 수치/미확인 메타데이터는 NULL과 부분 사유로 전달하고, 두 수치가 모두 무효이거나 시각이 무효/미래이면 기존 관측을 덮지 않는다. 등급을 인구수로 추정하거나 미확인 대체 여부를 N으로 바꾸지 않는다. 전처리의 필드 품질과 실제 DB 갱신 여부는 별개다.

`citydata_sections.py`는 `citydata-selected-v1` 필드 허용 목록, 봉투/장소 검증, missing/empty/invalid/usable 섹션 상태를 정의한다. 인구는 기존 채택 필드, 주차는 현재 전처리 소비 필드, 도로는 LINK_ID·XYLIST와 평균 자료의 원천 시각만 선택한다. 미지의 최상위 키·섹션 형태·제외 필드 이름은 기록하고 뉴스/날씨 등 미채택 값은 선택본에 복제하지 않는다. 주차 후보의 ID/좌표와 도로 좌표 품질은 사전 검사하되, 주차 요금/현황·중복/충돌·실제 DB 쓰기는 각 후속 결과로 구분한다.
