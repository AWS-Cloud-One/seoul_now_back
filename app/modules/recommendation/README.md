> 현재 공개 추천은 자연어 message/conditions/state 방식입니다. 구조화 서비스와 sessions.py는 내부 참고용으로 보존합니다.

# 추천 모듈

API_SPEC 0.12의 순위 규칙을 적용합니다.

- `ranking.py`: 분 단위 내림 ETA → 같은 구간 모두 주차 거리 확인 시 직선거리 → 장소 ID 문자열순.
- `evidence.py`: 주변 등록 주차 기록 중 최단 거리 선택. 도로 정보는 참고용이며 순위에 미반영.
- `sessions.py`: R01의 서버 후보·페이지·노출 이력·중복 요청 응답 저장.
- `state.py`: 이전 자연어 서비스의 내부 상태 코덱. 공개 R01에서 사용하지 않음.

잔여 면수·도로 혼잡도는 추천 순위에 사용하지 않습니다.
R01은 구조화 계약을 사용합니다. 최신 DB·보류된 상세/재확인 계약 통합은 별도입니다.
자세한 동작과 남은 계약 차이는 `docs/RECOMMENDATION_GUIDE.md`를 확인하세요.
