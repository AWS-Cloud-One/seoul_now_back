# 프롬프트

조건 해석과 추천 설명의 프롬프트를 분리해 관리한다.

- `interpretation.txt`: 메시지와 현재 조건에서 명시한 변경만 추출한다. 좌표·후보를 생성하지 않고, 누락과 명시적 해제를 구분한다. 출발지는 서버가 검색·검증하며 미지원 요청은 안내 대상으로 분류한다.
- `explanation.txt`: 확정된 후보 순서와 서버 근거 문구의 키만 선택한다. 모델의 임의 문장·숫자는 사용하지 않는다.

기존 추천 브랜치의 프롬프트를 현재 Conditions·추천 카드 계약에 맞췄다. 출력 타입과 검사는 각각 상위 `interpretation.py`, `explanation.py`에 있다. 모의 출력 검증은 `tests/unit/ai/`와 `tests/api/test_recommendation_integration.py`에서 수행하며 실제 자연어 품질 검증은 별도다.

프롬프트 추가 시 목적, 허용 입력, 출력 Schema, 변경 이유와 대응하는 테스트 사례를 함께 기록한다. 공유하는 고정 입력·모의 응답은 `tests/fixtures/`에 둔다. API 키·운영 대화·정밀 위치를 템플릿에 하드코딩하지 않는다.
